## Key Notebooks Summary

### planarity_prediction.ipynb
- Evaluates planarity prediction accuracy and IoU
- Compares predictions against ground truth
- Visualizes planarity masks

### hipersim.ipynb
- Explores Hypersim dataset structure
- Loads and visualizes RGB (HDR), depth, normals, semantics
- Tests plane label loading

### scene_understanding.ipynb
- Full scene understanding pipeline
- Plane extraction and segmentation
- 3D visualization

### planarity2segmentation.ipynb
- Converts planarity masks to plane segmentations
- Tests different segmentation algorithms
- Evaluates segmentation quality
